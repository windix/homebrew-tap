# Windix Tap

## Formulae

| Formula | Description |
| --- | --- |
| [`vcs`](Formula/vcs.rb) | Video Contact Sheet *NIX: creates contact sheets (previews) of videos. Maintained fork of the [disabled homebrew-core formula](https://formulae.brew.sh/formula/vcs), built from [windix/video-contact-sheet](https://github.com/windix/video-contact-sheet). |

## How do I install these formulae?

`brew install windix/tap/<formula>`

Or `brew tap windix/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "windix/tap"
brew "<formula>"
```
